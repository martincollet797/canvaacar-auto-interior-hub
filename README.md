## About Canvaacar

Canvaacar is a static website dedicated to displaying automotive interior services, covering seat renovation, headliner and roof lining work, and wider interior customization. Visitors can explore available materials like leather and Alcantara and review visual examples of finished projects.

The site targets customers looking to refresh or personalize a vehicle cabin. A bilingual French and English interface, service presentation, before-and-after gallery, and contact pathways give visitors a straightforward way to discover options and request a quote.

---

## Features

- Presentation of seat and headliner renovation services
- Showcase of automotive interior customization
- Gallery of before-and-after projects
- Materials overview highlighting leather and Alcantara
- French and English language interface
- Custom internationalization built with HTML, CSS, and JavaScript
- Contact and quote request form
- WhatsApp and phone contact options

## Installation

Canvaacar is a static website and needs no server-side runtime.

```bash
git clone https://github.com/martincollet797/canvaacar-auto-interior-hub.git
cd REPO
```

For a local preview, open the main HTML file in a browser, or serve the directory with any static web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Usage

1. Open the website in a modern browser.
2. Choose French or English with the language controls.
3. Browse the renovation and customization services.
4. Review the materials and the before-and-after gallery.
5. Submit an inquiry through the contact or quote request form.
6. Use the available WhatsApp or phone contact option if you prefer.

To publish, upload the static project files to a web host that serves HTML, CSS, JavaScript, and media assets.

## Configuration

Language labels and translated content are handled by the project's custom internationalization logic. When changing interface text or adding content for a supported language, update the relevant JavaScript translation data.

Service descriptions, gallery entries, materials, and contact details can be adjusted in the corresponding HTML and JavaScript assets. After changes, reload the site in both supported languages to check layout and translated content.

## FAQ

### Is Canvaacar a desktop application?

No. Canvaacar is a web-based static site that runs in a browser.

### Which languages are supported?

The interface supports French and English through the project's custom internationalization system.

### How can visitors request a quote?

Visitors can use the contact and quote request form or select the available WhatsApp and phone contact options.

### Where are the services and materials shown?

The site includes dedicated content for automotive interior services and materials such as leather and Alcantara, along with a before-and-after gallery.

### How do I update the website content?

Edit the relevant HTML content and translation data in the project files, then refresh the site locally to review the changes.

### What should I check if the page does not load correctly?

Confirm that the project is being opened from the correct directory, verify asset paths, and use a local static server if browser restrictions affect local files. Inspect the browser console for JavaScript or translation errors.

### How are updates published?

Build or edit the static files, test both language versions, and deploy the updated contents to the configured static hosting location.
